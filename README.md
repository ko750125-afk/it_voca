# IT Voca

IT 입문자와 바이브코딩 학습자를 위한 모바일 IT 용어 플래시카드 앱입니다.

## 주요 기능
- IT 용어 플래시카드 학습
- 3D 플립 애니메이션 지원
- 항목별(발음, 약자, 뜻, 해설) 가리기 기능
- 오프라인 기반 (SQLite 저장소 사용)

## 기술 스택
- React Native (Expo)
- TypeScript
- Expo Router
- expo-sqlite
- react-native-reanimated

## 시작하기

```bash
# 종속성 설치
npm install

# 앱 실행
npx expo start
```
